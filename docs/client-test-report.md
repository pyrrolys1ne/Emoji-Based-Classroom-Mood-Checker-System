# 客户端验证结果

本报告记录客户端独立验证与正式后端接口核对。客户端实现覆盖学生完整流程、教师基础页、API 适配、独立演示模式和异常状态。正式后端业务仍为占位，真实跨端集成尚未通过。

| npm run build       | 通过      | 管理端及客户端生产构建                               |

浏览器测试使用演示数据或受控 HTTP 响应；本地 Chromium 项目通过已安装 Edge 148.0.3967.96 的隔离实例执行，Firefox 使用 Playwright 下载的 157.0。手机项目为触控视口模拟，未声称实际手机设备验证。客户端 CI 安装其锁定的 Chromium 与 Firefox 后执行同一套流程，远端执行结果以对应提交的 Actions 为准。

## 覆盖的关键行为

- 学生注册、登录、提交、历史、刷新恢复、改密后重新登录和退出。
- 请求期间防重复点击和课堂切换，失败保留选择，401 清理身份，退出后迟到响应不恢复个人数据。
- 教师课堂选择、整体统计、学生筛选、首载失败重试；AI 记录始终匿名，不依赖输入中的用户编号。
- API 请求字段和身份头、错误状态、非 JSON、无效数据、超时、取消和离线；501 不进入演示成功。
- 演示学生／教师范围、未开放课堂、未审批教师申请、过期和撤销会话、无明文密码持久化、损坏及不可用存储、并发写入。
- API 返回超出当前学生或课堂范围的历史时停止展示；该客户端检查不替代服务端 RBAC。

## 正式后端实际响应

对当前正式 FastAPI 应用在隔离本地端口发起实际 HTTP 请求，使用合成输入和无效合成令牌，不使用正式用户数据：

| 请求                                    | 实际状态            | 含义                          |
| --------------------------------------- | ------------------- | ----------------------------- |
| GET /api/health                         | 200 OK              | 应用可运行，stage 为 scaffold |
| POST /api/auth/register                 | 501 NOT_IMPLEMENTED | 注册未实现                    |
| POST /api/auth/login                    | 501 NOT_IMPLEMENTED | 登录未实现                    |
| GET /api/sessions，无身份               | 401 UNAUTHENTICATED | 拒绝未认证访问                |
| GET /api/sessions，合成占位令牌         | 501 NOT_IMPLEMENTED | 尚无真实用户认证与课堂查询    |
| POST /api/emoji，合成占位令牌           | 501 NOT_IMPLEMENTED | 无手动记录业务                |
| GET /api/emoji/history，合成占位令牌    | 501 NOT_IMPLEMENTED | 无持久历史业务                |
| GET /api/emoji/statistics，合成占位令牌 | 501 NOT_IMPLEMENTED | 无基础统计业务                |
| POST /api/auth/logout                   | 404 NOT_FOUND       | 正式后端尚无注销路由          |

后端占位版本基线为 9e0f5fc。上述验证说明接口阻塞的实际来源，不代表真实身份、学生／教师权限或数据库持久化已经通过。

## 待完成的集成验收

后端维护模块需提供真实账号与认证、可见课堂、教师注册／授予流程、手动保存与查询、基础统计、注销，以及明确的改密会话、课堂时段和重复反馈规则。按 [客户端对接约定](client-integration.md) 提供测试数据和响应样例后，执行 [验收清单](client-acceptance.md) 中的真实身份、持久性、越权、跨端看板／CSV 和受控重启测试。

客户端独立实现和验证已完成；正式后端、管理端与客户端使用同一条真实记录的最终验收仍等待上述能力，不能由演示测试替代。
