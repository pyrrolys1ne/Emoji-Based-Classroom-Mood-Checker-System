1. 当前趋势图展示反馈条数的时间变化，情绪构成另有分布图；尚未提供各情绪占比随时间变化的曲线。按实际图义演示，严格验收“情绪趋势”时需说明这一口径。

3. DeepFace 本地模型、完整摄像头干扰场景、另一台真实设备的 IP 访问未在本次回归中验证。移动视口自动化不等同于真实手机测试。
