# 全量统计与 CSV 导出

正式后端使用 PostgreSQL 对授权范围内的完整记录聚合，统计不依赖历史分页或浏览器已加载行。三类查询共用 [历史接口](backend-feedback.md) 的筛选与权限规则，模拟数据遵守 [AI 入库](backend-ai-ingestion.md) 的隔离配置。健康接口 stage 为 realtime-ai-control，实时看板与 AI 控制代理见 [实时说明](backend-realtime-ai.md)。

## 接口与过滤

| 接口                        | 身份         | 成功 data 或内容                                         |
| --------------------------- | ------------ | -------------------------------------------------------- |
| GET /api/emoji/statistics   | 教师、管理员 | 统一包装中的 EmotionStatistics                           |
| GET /api/admin/statistics   | 教师、管理员 | 统一包装中的 MultidimensionalStatistics                  |
| GET /api/admin/emoji/export | 管理员       | UTF-8 BOM 的 CSV 文件，Content-Disposition 为 attachment |

所有接口携带用户 Bearer 令牌。教师按课堂实际 teacherId 限制范围，课程默认教师变化不转移课堂权限；管理员查询全部。学生不能查询统计或导出，教师不能导出，独立 AI 服务令牌不能调用这些接口。业务事务会重新验证会话和角色。

过滤条件全部可选且取交集：

| 参数      | 含义                                                         |
| --------- | ------------------------------------------------------------ |
| sessionId | 课堂 UUID；不存在返回 404，显式越权返回 403                  |
| userId    | 手动记录所属用户 UUID；与教师可见范围继续取交集，AI 用户为空 |
| course    | 课程 UUID                                                    |
| class     | 课堂班级精确匹配，不使用学生当前所属班级代替                 |
| from、to  | 带时区的 ISO 8601 时间，按实际时间比较；起点包含、终点不包含 |
| source    | MANUAL、AI、ALL；统计与 CSV 默认 MANUAL，历史默认 ALL        |
| emotion   | 九种共享情绪之一，历史同样支持                               |
| format    | 仅 CSV 支持，默认且仅允许 csv                                |

无时区、from 不早于 to、非法 UUID、非法来源、未知参数均返回 422，不回退到无筛选查询。筛选不存在的课程、学生或班级可返回空结果。学生被移出当前名单后，相关既有记录继续计入教师所授课堂的历史与统计。所有成功及错误响应均为 Cache-Control: no-store。

## 分布、趋势和分组

基础统计 data 为 `{total,distribution,source}`，distribution 完整包含 HAPPY、FOCUSED、NEUTRAL、CONFUSED、SAD、ANGRY、SURPRISED、FEAR、DISGUST，缺失情绪计 0；总和等于 total。默认统计手动反馈，来源切换后分母为同一范围、同一来源的记录条数。AI 采样数不表示学生人数，模型输出不表示心理状态、专注程度或学习效果。

多维统计继承上述字段，并返回：

- timeline：`{startsAt,endsAt,total}[]`，UTC 升序时间桶。使用匹配数据的最早 UTC 分钟为起点，以覆盖最晚分钟为目标，步长为整数分钟并自适应为最多 12 桶；中间无记录的桶计 0，桶区间为 `[startsAt,endsAt)`。桶的覆盖边界可宽于过滤边界，但计数只包含原过滤范围内的记录。相同分钟数、不同小时或日期不会误合并。
- groups：`{courseId,courseName,className,total,manual,ai}[]`，仅含非空课程班级分组，按课程名称、编号、班级排序；manual+ai=total。

每次多维统计仅使用一次聚合 SQL 的结果形成分布、趋势和分组，三者的合计相等。数据库先按来源、情绪、完整分钟和课程班级聚合，再合并趋势桶，不读取分页历史。空结果 total 为 0，九种分布均为 0，timeline 与 groups 为 []。不同请求分别读取当时的数据；有新反馈期间，各次请求可反映不同快照。

## CSV 格式与安全

列顺序固定为：记录编号、课堂编号、用户编号、用户、学号、课程、班级、情绪、来源、模型分数、记录时间、设备标识、模拟输入、推理提供方、分数类型。情绪和来源使用共享枚举；时间统一 UTC；模拟输入为“是”或“否”。AI 的用户编号和学号为空，用户为“匿名”，设备为结构化设备标识；不导出图像、特征、邮箱、密码、令牌、幂等键或请求摘要。

DeepSeek 记录保留提供方和 self_reported；“模型分数”不表示准确率或已校准概率。默认排除模拟记录，隔离开发环境显式开启后，模拟标记不会消失。

CSV 使用 UTF-8 BOM、CRLF 行结束符和标准双引号转义，所有单元格加引号。逗号、引号、回车和换行保留在单元格内；公式前缀及其前置空白或 BOM 增加文本前缀，防止表格软件执行公式。空结果只返回表头。

导出与统计采用相同过滤逻辑，不受浏览器 10 行分页影响；按 recordedAt 降序、id 降序稳定排列。导出生成与 EMOJI_CSV_EXPORT 审计在同一事务内完成，目标为指定课堂或空，提交成功后才返回文件。生成、数据库或审计失败返回统一 JSON 错误，不返回半份 CSV。

## 前端接入

正式管理端多维统计调用服务端接口，图表和课程班级汇总使用同一响应。切换课堂、课程、班级、日期时间或来源时中止旧请求，迟到响应不会覆盖新筛选。默认 MANUAL，选择 AI 或 ALL 后显式携带来源。界面失败时显示错误，不使用演示数据代替正式响应。

记录页面默认手动来源，可切换 AI、全部来源并筛选情绪；管理员点击 CSV 时，浏览器携带身份和当前来源、情绪、课堂请求服务端文件。下载失败不创建虚假文件，切换筛选或退出后取消旧下载；教师按钮不可用且服务端拒绝越权。演示和独立联调模式保留浏览器导出与全量聚合，不冒充正式数据库结果。

学生客户端的教师页面支持统计来源切换，默认 MANUAL。统计独立于历史中的学生筛选；切换来源时旧响应不恢复旧统计。保留共享 source 可选以兼容旧参考服务，正式后端始终返回 source。

## 运行与验证

统计与导出不新增迁移；当前完整数据库版本为 001—007，实时功能所需的 007 升级见 [实时说明](backend-realtime-ai.md)。配置、依赖与测试数据库见 [数据库说明](backend-database.md)。设置 MOOD_TEST_DATABASE_URL 后，在 services/backend 执行 `../../.venv/bin/python -m pytest -q`；测试创建独立临时 PostgreSQL 数据库。

验证包括角色与课堂范围、名单移除、来源与模拟隔离、九种情绪、空结果、UTC 趋势、跨日和时区、半开时间范围、组合过滤、超过 1,000 条记录、统计与 CSV 编号一致、公式防护、引号换行及审计失败。前端执行 `npm run typecheck`、`npm run test:client`、`npm run test:admin`、`npm run build`，验证来源切换、回执格式、CSV 下载和迟到响应处理。
